## Component API

### ButtonGroup

The `ButtonGroup` component arranges related buttons as a single control.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
| `orientation` | `"horizontal" \| "vertical"` | `horizontal` |

### ButtonGroupText

The `ButtonGroupText` component renders text inside a button group.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
