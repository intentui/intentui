## API

### FileTrigger

The `FileTrigger` component opens the system file picker from a styled trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
| `intent` | `"primary" \| "secondary" \| "warning" \| "danger" \| "success" \| "outline" \| "plain"` | `outline` |
| `isCircle` | `true \| false` | `false` |
| `isDisabled` | `boolean` | - |
| `isPending` | `boolean` | - |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "sq-xs" \| "sq-sm" \| "sq-md" \| "sq-lg"` | `md` |
