## Component API

### ColorSlider

The `ColorSlider` component lets users adjust one color channel.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### ColorSliderOutput

The `ColorSliderOutput` component displays the current color slider value.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### ColorSliderTrack

The `ColorSliderTrack` component renders the color slider track.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

See the [React Aria](https://react-aria.adobe.com/ColorSlider#api) for the full API reference.
