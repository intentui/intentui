## Basic
When you install a color that requires dragging, you'll need a color thumb. Naturally, you wouldn’t want to install it manually. So, for each color that requires this component, it will be installed automatically.
<How toUse="colors/color-area/color-area-channel-demo" />

## Installation
```bash
npx shadcn@latest add @intentui/color-thumb
```

## Manual installation
```bash
npm i react-aria-components
```
