## Component API

### ScrollArea

The `ScrollArea` component renders custom scrollable content.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
| `orientation` | `ScrollAreaOrientation` | `both` |
| `scrollbarGutter` | `boolean` | `false` |
| `scrollFade` | `boolean` | `false` |
