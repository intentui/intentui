## Component API

### DateField

The `DateField` component lets users enter a date with segmented fields.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### DateInput

The `DateInput` component renders the segmented date input.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

See the [React Aria](https://react-aria.adobe.com/DateField#api) for the full API reference.
