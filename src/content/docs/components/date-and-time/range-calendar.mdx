## Component API

### RangeCalendar

The `RangeCalendar` component lets users select a date range.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
| `visibleDuration` | `RangeCalendarProps<T>["visibleDuration"]` | `{ months: 1 }` |

See the [React Aria](https://react-aria.adobe.com/RangeCalendar#api) for the full API reference.
