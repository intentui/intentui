## Component API

### Checkbox

The `Checkbox` component is used for a single selectable option.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### CheckboxGroup

The `CheckboxGroup` component groups related checkbox options.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### CheckboxLabel

The `CheckboxLabel` component renders the checkbox label.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

See the [React Aria](https://react-aria.adobe.com/Checkbox#api) for the full API reference.
