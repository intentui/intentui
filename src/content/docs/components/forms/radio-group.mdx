## Anatomy
```
import { Description, Label } from "@/components/ui/field"
import { Radio, RadioGroup } from "@/components/ui/radio"
```

```
<RadioGroup name="billing">
  <Label>Billing Cycle</Label>
  <Description>
    Select how often you'd like to be billed
  </Description>

  <Radio value="monthly">
    <Label>Monthly</Label>
    <Description>Billed every month</Description>
  </Radio>
  <Radio value="quarterly">
    <Label>Quarterly</Label>
    <Description>Billed every 3 months</Description>
  </Radio>
  <Radio value="yearly">
    <Label>Yearly</Label>
    <Description>
      Billed once per year with a discount
    </Description>
  </Radio>
</RadioGroup>
```

## Component API

### Radio

The `Radio` component represents one radio option.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### RadioGroup

The `RadioGroup` component groups mutually exclusive radio options.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

See the [React Aria](https://react-aria.adobe.com/RadioGroup#api) for the full API reference.
