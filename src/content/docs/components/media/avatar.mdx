## Installation

Install the component via the CLI in one command.
<PackageCommand command="npx shadcn@latest add @intentui/avatar"/>

## Manual installation
Use this approach if you prefer to install and wire up the component yourself instead of using the CLI.
<PackageCommand command="npm i cn"/>
<SourceCode toShow='avatar'/>

## Anatomy
```
import { Avatar } from "@/components/ui/avatar"

<Avatar
  src="https://intentui.com/images/avatar/slash.jpg"
  alt="Slash"
  initials="Sl"
/>
```

## Examples

### Fallback
If the image fails to load, the avatar will fallback to the initials.
<How toUse="media/avatar/avatar-initials-example" />

### Shape
By default, the avatar is a `circle`. You can change it to a square by using the `isSquare` props.

<How toUse="media/avatar/avatar-shape-example" />

### Size
By default, the avatar is medium. You can change it to small, large or extra-large by using the `size` prop.

<How toUse="media/avatar/avatar-size-example" />

### Avatar group
You can use the `AvatarGroup` component to display a group of avatars.

<How toUse="media/avatar/avatar-group-example" />
