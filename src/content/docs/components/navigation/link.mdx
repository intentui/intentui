## Installation

Install the component via the CLI in one command.
To install the required package, run the following command:

<InstallCommand command="npm i react-aria-components"/>

## Anatomy
```
import { Link } from "@/components/ui/link"

<Link href="#basic">Label</Link>
```

## Client side routing
Integrating `Link` with your framework’s link component is straightforward. Learn more in [Client Side Routing](/docs/getting-started/client-side-routing).

## Component API

The `Link` component navigates to another page or resource.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

See the [React Aria](https://react-aria.adobe.com/Link#api) for the full API reference.
