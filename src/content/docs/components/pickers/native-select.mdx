## Anatomy

```ts
import { Description, Label } from '@/components/ui/field'
import { NativeSelect, NativeSelectContent } from '@/components/ui/native-select'
```

```tsx
<NativeSelect>
  <Label>Role</Label>
  <NativeSelectContent>
    <option value="owner">Owner</option>
    <option value="admin">Admin</option>
    <option value="member">Member</option>
    <option value="viewer">Viewer</option>
  </NativeSelectContent>
  <Description>Pick the default permission level for new teammates.</Description>
</NativeSelect>
```

## Component API

### NativeSelect

The `NativeSelect` component wraps a native select control.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### NativeSelectContent

The `NativeSelectContent` component renders the native select element.

| Prop        | Type      | Default |
| ----------- | --------- | ------- |
| `className` | `string`  | -       |
| `isInvalid` | `boolean` | -       |
