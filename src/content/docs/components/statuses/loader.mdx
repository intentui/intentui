## Component API

The `Loader` component displays loading feedback.

| Prop | Type | Default |
| --- | --- | --- |
| `formatOptions` | `Intl.NumberFormatOptions` | - |
| `isIndeterminate` | `boolean` | `true` |
| `percentage` | `number` | - |
| `variant` | `keyof typeof LOADERS` | - |
