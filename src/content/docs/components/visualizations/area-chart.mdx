## API

### AreaChart

The `AreaChart` component renders continuous data trends with filled areas.

| Prop | Type | Default |
| --- | --- | --- |
| `areaProps` | `Partial<ComponentProps<typeof Area>>` | - |
| `chartProps` | `Omit<ComponentProps<typeof AreaChartPrimitive>, "data" \| "stackOffset">` | - |
| `connectNulls` | `boolean` | `false` |
| `fillType` | `"gradient" \| "solid" \| "none"` | `gradient` |
