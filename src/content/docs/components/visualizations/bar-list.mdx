## Component API

The `BarList` component displays ranked values as horizontal bars.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |
| `data` | `Bar<T>[]` | `[]` |
| `onValueChange` | `(payload: Bar<T>) => void` | - |
| `sortOrder` | `"ascending" \| "descending" \| "none"` | `descending` |
| `valueFormatter` | `(value: number) => string` | `(value) => value.toString()` |
