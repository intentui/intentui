## Command Line Interface (CLI)
The CLI is designed to help you set up your project with Intent quickly and efficiently. It’s the easiest and most convenient way to install Intent, allowing you to get started with your project in just minutes.

## Existing Project
If you already have a project set up—whether it’s built with Laravel, Next.js, Remix, Tanstack, or any other framework—simply run the following command to install Intent:

## Add

The `add` command lets you install various types of components from the registry like UI components, hooks, libraries, styles, and more.
By default, it installs UI components (`--type ui`), so you don’t need to specify the type unless you're adding something else.

### Components

Once you’ve set up Intent, you can start adding components easily using the `add` command:

To add a library like `primitive`, use the `--type lib` option:

### Style

It currently offers 5 starter styles, including `blue`, `indigo`, `emerald`, and `sky`.
You can swap out `default` with any style you prefer:

<Installation command='npx @intentui/cli@latest add --type style blue'/>

## Alias
If you’re tired of typing `npx @intentui/cli@latest`, you can create an alias for the CLI by adding the following line to your `.bashrc` or `.zshrc` file:
```
alias intentui='npx @intentui/cli@latest'
```
Then you can run the CLI using the `intentui` command:
```
intentui [command]
```

## Shadcn CLI

We ship our own CLI, but you can use the shadcn CLI if you prefer. To get started, initialize your app with the command below.

Before you proceed, make sure your project uses the namespace. If you are not familiar with it, read the guide [here](https://ui.shadcn.com/docs/registry/namespace).

```
"registries": {
  "@intentui": {
      "url": "https://intentui.com/r/{name}"
  }
}
```

<Installation options={{ isComponent: false, noText: true }}
              command='npx shadcn@latest init https://intentui.com/r/style/default'/>

It currently offers 5 starter styles, including `blue`, `indigo`, `emerald`, and `sky`, so you can replace `default` with any style you prefer.

Once initialized, you can add components by running:
<Installation options={{ isComponent: false, noText: true }}
              command='npx shadcn@latest add @intentui/ui/<component>'/>

Let’s say you want to add a card component. Just replace `<component>` with `card`, like this:

<Installation options={{ isComponent: false, noText: true }}
              command='npx shadcn@latest add @intentui/ui/card'/>
