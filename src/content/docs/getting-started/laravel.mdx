## Laravel installer

Start making your Laravel project with Intent UI using the Laravel Installer. If you haven't installed the Laravel Installer yet, you can go to the [Laravel documentation](https://laravel.com/docs/12.x/installation#creating-a-laravel-project) to get started.

```bash
laravel new app --using=intentui/laravel
```

## Composer

Alternatively, if you're using Composer, install Intent UI with the command below:

```bash
composer create-project intentui/laravel app
```

Once installed, you can start adding components to your project by running:

## Source code

You can also clone the repository to get started right away. Clone the latest version from the [GitHub repository](https://github.com/intentui/laravel).
